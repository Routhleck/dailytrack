- [ ] Release only includes local-first agreed MVP scope.

## Quality Gates
- [ ] QA checklist fully passed.

## Packaging Readiness
- [ ] Tauri dev build works locally.
- [ ] Production build command succeeds.
- [ ] Default data root bootstrap verified.
