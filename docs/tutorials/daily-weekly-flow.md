# Daily + Weekly Tracking Workflow

## Daily Rhythm

1. Morning: open `Daily Note` and review checklist.
2. During day: check items as they complete.
3. Night: write `One Line` + mood/energy.

## Weekly Rhythm

1. At week start: open `Weekly Note` and define focus items.
2. Mid-week: update section checklists.
3. Week end: complete reflection fields.

## Helpful Views

- `Daily History`: calendar-based review.
- `Weekly History`: year/week grid review.
- Dashboard heatmap: quick streak visibility.

## Quality Habit

- Keep checklist items small and concrete.
- Use template updates sparingly; prefer merge mode.
