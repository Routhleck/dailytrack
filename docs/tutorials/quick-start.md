# Quick Start in 5 Minutes

## 1. Install

1. Download latest release from GitHub.
2. Install package for your platform.
3. Launch app and finish onboarding.

## 2. Understand Data Location

Default data root:

- macOS/Linux: `~/dailytrack-data`
- Windows: `%USERPROFILE%\\dailytrack-data`

Main profile path:

- `profiles/default/`

## 3. Create First Records

1. Open `Daily Note` and check a few items.
2. Open `Weekly Note` and add section progress.
3. Open `Body` and add one record.

## 4. Verify Autosave

- Type into Daily/Weekly and wait for debounce save.
- Close and reopen page to confirm content persists.

## 5. Optional: Enable Sync

- Open Settings and configure WebDAV.
- Test connection before first push.
