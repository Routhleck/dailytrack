# Body Tracking Basics

## Record Structure

`body.csv` supports:

- `date`
- `weight`
- `waist`
- `bodyFat`
- `muscleMass`
- `chest`
- `hip`
- `note`

## Basic Flow

1. Add one record per day (or per measurement event).
2. Keep date format consistent (`YYYY-MM-DD`).
3. Use note field for context (sleep, workout, stress).

## Preferences

- Toggle visible metrics by profile.
- Configure unit/decimals for chart + table readability.
- Set goal lines if needed.

## Review Habit

- Compare latest vs previous deltas weekly.
- Use chart range controls (`7d/30d/90d/all`) for trend context.
