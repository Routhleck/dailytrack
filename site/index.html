Tutorial Center

Everything you need to start, sync, and recover — directly on this page.

Quick Start in 5 Minutes

  1. Install from latest release and finish onboarding.
  2. Open Daily Note, Weekly Note, and Body once each.
  3. Check autosave by reopening the same note page.
  4. Confirm your data root path in Settings.

Daily + Weekly Operating Rhythm

  1. Morning: review Daily Core checklist.
  2. During day: update checklist and one-line notes.
  3. Week-end: fill Weekly reflections and next-week priorities.
  4. Use history pages for calendar/week-grid review.

Body Tracking Basics

  1. Add one record with date + key metrics.
  2. Configure visible metrics and units in Preferences.
  3. Use trend ranges (7d/30d/90d/all) for weekly review.
  4. Attach context in note field for better interpretation.

WebDAV Sync Tutorial

  1. Set URL/credentials and run Test Connection first.
  2. Do one manual Push Now to establish baseline snapshot.
  3. Use Sync page for Push/Pull/Both operations.
  4. Resolve conflicts with preview before batch apply.

Recovery & Safety Tutorial

  1. Profile deletes go to `.trash` instead of hard deletion.
  2. Use in-session Undo immediately after mistaken delete.
  3. Review destructive sync actions in confirmation dialog.
  4. Keep periodic zip exports as offline backup.
